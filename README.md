# Infinite-Corridor
# THE ENDLESS CORRIDOR (无尽长廊)

A 3D First-Person psychological horror game built purely with HTML and Three.js. No external assets; all textures and audio are generated in real-time via code.

一款基于原生 HTML 和 Three.js 打造的 3D 第一人称恐怖生存小游戏。无需任何外部图片或音频素材，所有贴图与音效均由代码实时生成。

## 🎮 Gameplay / 游戏简介
You are trapped in an endless looping corridor. A monster is approaching ahead, and a more terrifying entity is chasing you from behind. Kill the monster behind you to survive.
你被困在了一条无限循环的黑暗长廊中。前方有怪物逼近，背后有更恐怖的东西在追逐你。找到机会击杀背后的怪物才能逃出生天。

## 🕹 Controls / 操作说明
*   **W / S**: Move / 移动
*   **Shift**: Run / 奔跑 (消耗体力)
*   **Q**: Look back / 回头 (吓退背后的怪物)
*   **F**: Fire / 开火 (仅能攻击身后的怪物)
*   **R**: Drink Potion / 喝药水 (获得护盾)
*   **Esc**: Pause / 暂停

## 🛠 Tech Stack / 技术特性
*   **Three.js (WebGL)**: 3D rendering and dynamic lighting.
*   **Procedural Generation / 全程序化生成**: Wall textures and sound effects are generated dynamically.
*   **Post-Processing Shader / 后期处理着色器**: Simulates retro CRT/Film filters, scanlines, grain, and cinematic blinking effects.
*   **Mobile Friendly / 移动端适配**: Touch controls for mobile devices.

点击右侧的 GitHub Pages 链接在线游玩，或下载 `index.html` 在浏览器中打开。
